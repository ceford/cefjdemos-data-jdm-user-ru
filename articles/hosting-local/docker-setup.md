## Настройка локального окружения Joomla с использованием Docker

Для запуска Joomla на компьютере нужны четыре вещи: 
- загрузка и настройка веб-сервера **Apache** или **nginx**, 
- служба базы данных, например **MySQL или** **MariaDB**, 
- и, конечно же, **PHP** 
- и **Joomla.** 

Чтобы все эти компоненты могли взаимодействовать друг с другом, большинство
из нас используют комплексные программные решения, такие как **XAMPP**,
**Laragon** или **FlyEnv**.

Однако традиционные настройки легко могут привести к конфликтам портов или
к тому, что серверы баз данных по непонятным причинам отказываются запускаться.
Когда локальный сервер выходит из строя, вам может потребоваться вручную
загружать и переустанавливать целые сайты Joomla снова и снова, чтобы
протестировать всего один PR, при этом вы рискуете потерять свою работу во
время исправления ошибки. Это отнимает ценное время, а исправления обычно
оказываются лишь временными мерами.

**Переход на Docker ([Узнайте о Docker](https://docs.docker.com/get-started/))** 
С Docker можно полностью отказаться от ручной настройки. Вместо установки
веб-серверов непосредственно на компьютер вы просто создаёте один файл
«рецепт». Docker автоматически загружает, изолирует и подключает всё в
фоновом режиме. Если что-то выходит из строя, вам не нужно переустанавливать
всю настройку — достаточно перезапустить контейнер.

В этом руководстве вы узнаете самый простой способ запустить локальное
окружение Joomla с использованием Docker, чтобы тратить меньше времени на
исправление серверов и больше — на участие в разработке.

### Предварительные требования

Перед началом вам нужно установить только одно: **Docker Desktop**.

- Загрузите его с сайта [**docker.com**](https://www.docker.com/) и запустите
  установщик
- В Windows оставьте отмеченной опцию «Use WSL 2 instead of Hyper-V» —
  это ускоряет работу
- Откройте Docker Desktop и дождитесь, пока в левом нижнем углу не появится
  зелёный статус **Engine running**.

![Docker Desktop](../../../en/images/hosting-local/docker-setup/01-docker-setup-desktop.png)

### Файл docker-compose.yml

Когда нескольким службам нужно взаимодействовать — например, веб-серверу
(Apache/Nginx), PHP и базе данных (MySQL/MariaDB), — используется специальный
файл оркестрации под названием `docker-compose.yml`. Этот файл служит
шаблоном проекта: в нём определяются все необходимые службы и способы их
взаимодействия. (Официальный образ Docker для Joomla на самом деле создан
на основе образа PHP и Apache. Это означает, что, используя только этот
образ Joomla, вы получаете PHP, Apache и Joomla в одном комплекте).

Сначала создайте на компьютере новую папку для проекта (например, на
рабочем столе создайте папку с названием `joomla-docker`).

Внутри этой папки создайте новый текстовый файл и назовите его точно так:

    docker-compose.yml

Откройте этот файл в любом текстовом редакторе (например, в VS Code или
Notepad), вставьте следующий код без изменений и сохраните файл:

```
    services:
      joomla:
        image: joomla:latest
        ports:
          - "8080:80"
        environment:
          - JOOMLA_DB_HOST=db
          - JOOMLA_DB_USER=joomla
          - JOOMLA_DB_PASSWORD=joomlapass
          - JOOMLA_DB_NAME=joomladb
        depends_on:
          - db
      db:
        image: mariadb:10.11
        environment:
          - MYSQL_ROOT_PASSWORD=rootpass
          - MYSQL_DATABASE=joomladb
          - MYSQL_USER=joomla
          - MYSQL_PASSWORD=joomlapass
        volumes:
          - db_data:/var/lib/mysql
    volumes:
      db_data:
```

### Запуск окружения

Откройте терминал (или PowerShell в Windows), перейдите в папку `joomla-docker`
и выполните:

```
    docker compose up -d
```

При первом запуске Docker загрузит образы Joomla и MariaDB, что в зависимости
от скорости вашего интернет-соединения может занять одну-две минуты. После
этого каждый последующий запуск будет практически мгновенным, как показано
ниже.

![Вывод терминала при запуске Docker](../../../en/images/hosting-local/docker-setup/02-docker-setup-terminal-transcript.png)

### Установщик Joomla

Откройте браузер и перейдите по адресу `http://localhost:8080`. Вы должны
увидеть экран установки Joomla.

![Настройка установщика Joomla: название сайта](../../../en/images/hosting-local/docker-setup/03-docker-setup-joomla-installer-sitename.png)

На первом экране укажите название сайта и данные администратора.

![Данные для входа в установщик Joomla](../../../en/images/hosting-local/docker-setup/04-docker-setup-joomla-installer-login-data.png)

Когда вы дойдёте до экрана **Настройка базы данных**, именно здесь
большинство пользователей сталкиваются с проблемами:

**Не вводите `localhost` в качестве имени хоста.**

Поскольку база данных работает в собственном контейнере, Joomla требуется
имя службы контейнера, а не localhost. Используйте следующие точные значения:

- **Тип базы данных:** MySQLi
- **Имя хоста:** `db`
- **Имя пользователя:** `joomla`
- **Пароль:** `joomlapass`
- **Имя базы данных:** `joomladb`

![Настройка базы данных в установщике Joomla](../../../en/images/hosting-local/docker-setup/05-docker-setup-joomla-installer-database-config.png)

Перейдите по всем шагам, завершите установку — и всё готово.

Закончив работу на день, выполните `docker compose stop`, чтобы приостановить
контейнеры и освободить память. В следующий раз сайт будет находиться ровно
в том состоянии, в котором вы его оставили.

### Распространённые проблемы

- **Страница по адресу localhost:8080 не загружается сразу после запуска:** Контейнеру
  базы данных требуется несколько секунд для завершения инициализации. Подождите
  30 секунд и обновите страницу.
- **Порт 8080 уже используется:** Измените `"8080:80"` на `"8081:80"` в файле
  compose и открывайте сайт по адресу `localhost:8081`.
- **Контейнеры запустились, но Joomla показывает ошибку базы данных:** Проверьте,
  что в установщике в поле имени хоста указано `db`, а не `localhost`.

### Совет профессионала: доступ к файлам Joomla для разработки

Прямо сейчас ваш сайт Joomla работает, но фактические PHP-файлы
скрыты внутри Docker-контейнера. Если вы хотите вносить вклад в Joomla,
тестировать PR или писать собственные плагины, вам нужны эти файлы на
вашем компьютере, чтобы открывать их в VS Code или вашем любимом редакторе.

Чтобы синхронизировать файлы из контейнера с вашим локальным жёстким диском,
достаточно добавить две строки (`volumes: `) и
(`- ./site_joomla:/var/www/html`) в раздел `joomla` вашего файла
`docker-compose.yml`, как показано ниже:

```yml
services:
  joomla:
    image: joomla:latest
    ports:
      - "8080:80"
    volumes:
      - ./site_joomla:/var/www/html
    # ... (rest of your settings)
```

**Что это делает:** 

При следующем запуске `docker compose up -d` Docker автоматически
создаст папку с названием `site_joomla` рядом с вашим compose-файлом. Он
скопирует в эту папку всё ядро Joomla (включая панель администратора,
компоненты и шаблоны).

![Обозреватель IDE с установкой Joomla в Docker](../../../en/images/hosting-local/docker-setup/06-docker-setup-ide-explorer.png)

Любые изменения кода, внесённые вами в эту папку на компьютере, мгновенно
обновятся внутри работающего контейнера! Теперь вы полностью готовы к локальной
разработке.

### Дополнительный совет 1: тестирование определённых версий Joomla и PHP

При тестировании PR сопровождающие часто просят вас провести тестирование
с определёнными версиями PHP. С XAMPP понижение или обновление версии PHP —
настоящий кошмар. С Docker это занимает две секунды.

Вместо использования `image: `**`joomla:latest`** в вашем
**`docker-compose.yml`** можно указать точные версии с помощью тегов. Например,
если вам нужно протестировать **Joomla 5.2** на **PHP 8.3**, просто измените
эту строку на: **`image: joomla:5.2-php8.3-apache`**

Снова запустите **`docker compose up -d`**, и Docker мгновенно заменит
окружение вашего сервера. Все доступные теги версий можно найти на
<a href="https://hub.docker.com/_/joomla" class="ng-star-inserted"
target="_blank" rel="noopener" data-hveid="0"
data-ved="0CAAQ_4QMahgKEwjl8vi347CTAxUAAAAAHQAAAAAQkgI">официальной странице
Joomla на Docker Hub</a>.

### Дополнительный совет 2: добавление phpMyAdmin

Если вы переходите с **XAMPP**, вам, возможно, не хватает визуального
интерфейса для просмотра базы данных. Вы можете легко добавить
**phpMyAdmin** в свою конфигурацию, добавив новый **блок сервиса** в конец
вашего файла **`docker-compose.yml`**:

```yml
    phpmyadmin:
        image: phpmyadmin/phpmyadmin:latest
        ports:
          - "8081:80"
        environment:
          - PMA_HOST=db
        depends_on:
          - db
```

Перезапустите контейнеры, и теперь вы сможете получить доступ к phpMyAdmin,
перейдя в браузере по адресу **http://localhost:8081**. Просто войдите,
используя **`joomla`** в качестве имени пользователя и **`joomlapass`** в
качестве пароля.
