## Введение

Теги предоставляют простой и эффективный способ организации и отображения материалов. 
**Компонент «Теги»** позволяет использовать отдельные теги для разных типов 
материалов, включая материалы, категории, контакты и новостные ленты. Он также позволяет создавать родительские и дочерние теги.

В отличие от **категорий** Joomla, где материалу можно назначить только одну категорию, одному материалу можно назначить несколько тегов, но назначать теги материалам необязательно.

После присвоения материалу определённого тега нажатие кнопки тега в материале, отображающем теги, перенаправит вас на страницу со списком всех материалов, которым присвоен этот тег. По этой причине теги часто используются для представления *отфильтрованных* списков материалов.

Теги можно добавлять в нескольких местах, что обеспечивает гибкость при их создании.

## Рекомендации

Перед началом работы определите назначение тегов на сайте, особенно если материалы будут добавлять другие пользователи. При неправильном добавлении и управлении теги могут стать контрпродуктивными. К распространённым проблемам относятся добавление авторами материалов новых ненужных тегов и тегов с ошибками в написании. Некоторые администраторы сайта могут изменить права доступа так, чтобы только определённые пользователи могли добавлять новые теги.

На следующем снимке экрана показано использование тегов на сайте со статьями о объектах Всемирного наследия ЮНЕСКО. В данном случае каждому тегу назначен отдельный цвет. 

![страница списка тегов](../../../en/images/tags/content-tags/01-tags-example.png)

После создания теги отображаются в виде ссылок в материалах, которым они присвоены. Стили и положение тегов определяются шаблоном сайта. Часто они оформляются в виде кнопок или меток.

Отображение тегов можно отключить для отдельных статей или всех статей! Это может показаться нелогичным, но такая возможность полезна, когда теги используются, например, для фильтрации материалов в определённых сценариях.

## Список тегов

- В меню панели администратора выберите **Компоненты → Теги**.

На этом снимке экрана показаны теги в структуре, используемой на многоязычном сайте.
Для каждого языка имеется список тегов с языковым тегом в качестве родительского. 
Родительский тег используется в модулях *Популярные теги* и *Похожие теги*.

![страница списка тегов](../../../en/images/tags/content-tags/02-tags-list.png)

Независимо от способа создания теги можно найти в этом списке.

- Нажмите кнопку **Создать** на панели инструментов, чтобы создать новый тег.
- Выберите **Заголовок** тега, чтобы отредактировать существующий тег.

### Вкладка «Параметры тега»

![форма редактирования тега, вкладка параметров с показанными классами bootstrap css](../../../en/images/tags/content-tags/03-edit-tag-details-tab.png)

- **Заголовок**. Это единственное *обязательное* поле. 
- **Псевдоним**. Создаётся из заголовка при сохранении.
- **Описание**. Рекомендуется всегда добавлять описание. Оно отображается в формах панели администратора и может быть полезно при использовании большого количества тегов.
- **Родитель**. Оставьте значение *Нет*, если у этого тега нет родительского тега. Или выберите родительский тег из списка, чтобы сделать этот тег дочерним.
- **Состояние**. По умолчанию для этого поля устанавливается значение *Опубликовано*. Можно выбрать значения *Не опубликовано*, *В архиве* или *В корзине*.
- **Доступ**. По умолчанию установлен уровень доступа «Публичный».
- **Примечание** и **Примечание к версии**. При необходимости можно добавить примечания.
- **Сохранить и закрыть**. Если вы создаёте несколько тегов, можно выбрать **Сохранить и создать**, чтобы создать новый тег.

### Вкладка «Параметры»

- **Макет**. Можно выбрать один из нескольких макетов, а также создать собственный макет с помощью переопределения шаблона.
- **CSS-класс ссылки тега**. По умолчанию теги отображаются в виде синей кнопки. Здесь можно указать классы для настройки внешнего вида тегов и назначения разным тегам разных цветов. Пример: `bg-danger-subtle border border-danger` — это классы Bootstrap, создающие розовую кнопку с красной рамкой.
- **Изображение анонса и полноразмерное изображение**. Установите изображения для тега — изображение анонса для списка тегов и/или полноразмерное изображение для страницы тега.

![форма редактирования тега, вкладка параметров с показанными классами bootstrap css](../../../en/images/tags/content-tags/04-edit-tag-options-tab.png)

### Вкладка «Публикация»

- Установите метаданные страницы тега для поисковой оптимизации (SEO).

## Альтернативные способы создания

### Из статьи

Новые теги можно добавлять при создании или редактировании статьи. На вкладке «Материал» статьи в поле **Теги** введите название нового тега и нажмите **Enter**, чтобы сохранить его и присвоить статье.

### Из категории

Теги можно добавлять при создании или редактировании категории. На вкладке **Категория** введите название тега в поле **Теги** и нажмите **Enter**, чтобы создать новый тег и присвоить его категории.

### Из контакта

Теги можно добавлять при создании или редактировании контакта. На вкладке **Создать/изменить контакт** введите название тега в поле **Теги** и нажмите **Enter**, чтобы создать новый тег и присвоить его контакту. Новые теги также можно добавлять при создании категорий контактов.

### Из новостной ленты

Теги можно добавлять при создании или редактировании новостной ленты. На вкладке  
**Новая/изменить новостную ленту** введите имя тега в **поле тегов** и нажмите
**Enter**, чтобы создать и назначить новый тег. Новые теги также можно добавлять
при создании категорий новостных лент.

## Управление тегами

Все новые теги, добавленные в Joomla, будут отображаться в списке тегов.
Используйте список тегов для поиска, открытия и изменения настроек тегов.

Список можно изменять несколькими способами:

- Ищите тег, используя полностью или частично его заголовок или псевдоним в поле поиска.
- Изменяйте порядок списка с помощью перетаскивания, чтобы оптимизировать порядок отображения.
- Публикуйте или снимайте с публикации теги с помощью кнопки в столбце «Статус».
- Выберите один или несколько тегов и используйте кнопку **Действия**, чтобы опубликовать, снять с публикации, архивировать, разблокировать или удалить выбранные теги.
- Выберите один или несколько тегов и используйте кнопку **Действия → Пакетная обработка**, чтобы задать язык или уровень доступа.

## Отображение тегов

После создания тегов на сайте они становятся доступными для использования в материалах и таких модулях, как **Популярные теги** и **Похожие теги**. В следующих примерах показано, как это может выглядеть на сайте с использованием шаблона **Cassiopeia** по умолчанию.

![теги, отображаемые в материале, а также модули популярных и похожих тегов](../../../en/images/tags/content-tags/05-tag-modules-site-view.png)

При выборе одного из тегов вы перейдёте на страницу со списком
всех материалов, назначенных этому тегу:

![пример использования тегов на сайте: чёрный лабрадор](../../../en/images/tags/content-tags/06-items-with-cultural-site-tag.png)

Список материалов представляет собой отфильтрованный список содержимого сайта с выбранным тегом.
Для упрощения поиска материалов по мере увеличения списка предусмотрено поле фильтра.
Также можно задать количество результатов, отображаемых в одном представлении.

## Конфигурация тегов

Отдельные теги наследуют настройки из параметров компонента «Теги». Нажмите кнопку
**Параметры** на панели инструментов страницы списка тегов, чтобы просмотреть доступные параметры тегов по умолчанию.

Параметры компонента «Теги» можно переопределить на уровне материала и/или пункта меню.

## Советы

- Помните, что теги используются в разных типах содержимого.
- К материалу можно добавить несколько тегов.
- Если вы не уверены, воспользуйтесь кнопкой «Справка» на панели инструментов.
