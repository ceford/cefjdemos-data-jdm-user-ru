## Назначение

Числовое поле позволяет вводить действительное число с возможностью добавления валюты или другого символа перед числом или после него. Элемент можно использовать как целочисленное поле со стрелками увеличения и уменьшения и диапазоном по умолчанию от 1 до 100. Однако в поле можно вводить действительные положительные или отрицательные значения. Например, `99.99` может отображаться для конечного пользователя как `£99.99`. Или `-273.15` может отображаться для конечного пользователя как `-273.15C`.

## Создание поля

### Вкладка «Общие»

![Создание числового поля](../../../en/images/fields/adding-custom-fields-number-field/01-fields-number-edit.png)

- **Тип** Число, который нельзя изменить после выбора.
- **Имя** Уникальное имя поля.
- **Метка** Переводимая метка поля.
- **Описание** Необязательное переводимое описание поля.
- **Обязательное** Установите значение *Да*, если это поле обязательно для заполнения.
- **Использовать только в подформе** *Да* или *Нет*.
- **Значение по умолчанию** Необязательное значение по умолчанию.
- **Минимум** Минимальное значение, которое можно выбрать с помощью стрелок вверх/вниз; по умолчанию — 1. Оно может быть отрицательным, поэтому установите его меньше наименьшего ожидаемого числа, **иначе нажатие стрелки вниз может удалить существующее число**.
- **Максимум** Максимальное значение, которое можно выбрать с помощью стрелок вверх/вниз; по умолчанию — 100. Установите его больше наибольшего ожидаемого числа, **иначе нажатие стрелки вверх может удалить существующее число**.
- **Шаг приращения** Величина, добавляемая к текущему значению поля или вычитаемая из него с помощью стрелок вверх/вниз. Это может быть целое число (по умолчанию — 1) или десятичное число, например 0.01. **Установите наименьшее значение, на которое нужно увеличивать или уменьшать число**.
- **Форматировать как валюту** Если выбрано, появляются дополнительные поля:
    - **Символ валюты** Это может быть отдельный символ, например `£` или `$`, либо строка символов, например `&deg;C`, которая отображается как *&deg;C*.
    - **Положение символа** Выберите *Перед* или *После* числа.
    - **Количество десятичных знаков** Обычно для валют используется значение 2, но в других контекстах оно может быть иным.

### Вкладка «Параметры»

#### Панель «Параметры формы»:

- **Заполнитель** Текст-заполнитель, отображаемый внутри поля в качестве подсказки пользователю о требуемом вводе.
- **Класс поля** Необязательный класс, добавляемый полю формы ввода данных.
- **Класс метки** Необязательный класс, добавляемый метке поля.
- **Доступно для редактирования в** Разрешённые интерфейсы редактирования: *Сайт*, *Панель администратора* или *Оба*.
- **Атрибут Showon** Условное отображение или скрытие поля в зависимости от значения других полей.

#### Панель «Параметры отображения»:

- **Класс отображения** Класс контейнера поля в выводе.
- **Класс значения** Класс значения поля в выводе.
- **Метка** *Показывать* или *Скрывать* метку в выводе. Если выбрано «Показывать»:
    - **Класс метки (вывод)** Класс метки в выводе.
- **Автоматическое отображение** Когда и где отображать поле:
    - **После заголовка**
    - **Перед отображаемым содержимым**
    - **После отображаемого содержимого**
    - **Не отображать автоматически**
- **Префикс** Текст, отображаемый перед значением поля.
- **Суффикс** Текст, отображаемый после значения поля.
- **Макет** Список доступных макетов.
- **Отображать только для чтения** Выберите *Наследовать*, *Да* или *Нет*.

#### Панель «Умный поиск»

- **Индекс поиска** Выбор между поиском и отсутствием поиска, а также метода поиска.

### Вкладки «Публикация» и «Права доступа»

Содержимое этих вкладок очевидно и рассматривается в других разделах.

## Ввод данных

Ввод данных: просто введите нужное значение. В этом примере указана температура кипения аргона:

![Ввод данных в числовое поле](../../../en/images/fields/adding-custom-fields-number-field/02-fields-number-data-entry.png)

**Внимание:** если введённое число находится за пределами минимального и максимального диапазона, заданного в параметрах создания поля, при наведении указатель мыши отобразит соответствующее сообщение, но предоставленная информация не является ограничением. Можно ввести число за пределами диапазона, и оно будет принято.
