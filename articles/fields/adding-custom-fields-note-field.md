## Назначение

Тип поля формы «заметка» позволяет создавать заголовки, тексты, описания и даже блоки предупреждений. Он также позволяет упорядочить настройки расширений, разделяя их с помощью полезных заголовков. Или добавлять описания для определённых настроек (без необходимости полагаться на всплывающие подсказки). Или добавлять любой другой нужный текст.

## Создание поля

### Вкладка «Общие»

![Создание поля заметки](../../../en/images/fields/adding-custom-fields-note-field/01-fields-note-edit.png)

- **Тип** Число, которое нельзя изменить после выбора.
- **Имя** Уникальное имя поля.
- **Метка** Переводимая метка поля.
- **Описание** Необязательное переводимое описание поля.
- **Использовать только в подформе** *Да* или *Нет*.
- **Заголовок заметки** Будет отображаться в форме ввода данных.
- **Содержимое заметки** Текст заметки.
- **Класс заметки** Любые существующие или новые классы. Класс по умолчанию *alert alert-info* создаёт блок предупреждения Boostrap.
- **Тег заголовка** Выберите один из списка уровней заголовков.
- **Показывать кнопку закрытия**  Это поле управляет отображением символа «x» для закрытия заметки. Оно принимает значение «true» (для предупреждений) или значение атрибута data-dismiss для значка закрытия Bootstrap.

### Вкладка «Параметры»

- **Автоматическое отображение** Определяет, отображать ли поле и где именно:
    - **После заголовка**
    - **Перед отображаемым содержимым**
    - **После отображаемого содержимого**
    - **Не отображать автоматически**
- **Макет** список доступных макетов.
- **Отображать во внешнем интерфейсе** *Да* или *Нет*.

## Ввод данных

В форме ввода данных поле заметки отображается среди других полей в виде текста, оформленного в соответствии с параметрами стиля, заданными для поля. Оно может содержать инструкции или информацию.

![Ввод данных для числового поля](../../../en/images/fields/adding-custom-fields-note-field/02-fields-note-data-entry.png)

**Совет:** Используйте механизм сортировки полей, чтобы определить порядок заметок среди других полей. Можно использовать несколько разных полей заметок для структурирования и предоставления информации о полях.

## Отображение данных

Если для параметра *Отображать во внешнем интерфейсе* установлено значение *Да*, поле заметки отображается среди других полей во внешнем интерфейсе. Там оно может содержать общую информацию, относящуюся к группе материалов.
