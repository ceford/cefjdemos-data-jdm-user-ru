## Назначение

Поле видео позволяет выбрать видеофайл из папки медиафайлов.
Оно также позволяет выбрать изображение, которое будет использоваться в качестве постера для видео,
обычно это первый кадр видео.

## Создание поля

Общие параметры полей описаны в отдельной статье.

* **Заголовок** Заголовок отображается и используется в списке полей.
* **Метка** Это отображается в выходных данных. Если оставить поле пустым, значение будет задано
из содержимого поля «Заголовок», но его можно изменить.

![создание поля видео](../../../en/images/fields/adding-custom-fields-video-field/01-fields-video-edit.png)

**Примечание:** В этом примере включение типа поля в заголовок предназначено только для
демонстрации. В собственных заголовках полей не указывайте его.

## Ввод данных

В использовании поле видео является простым. Вы выбираете необходимый видеофайл с помощью
медиаменеджера.

На следующем снимке экрана показан выбранный аудиофайл:

![ввод данных поля видео](../../../en/images/fields/adding-custom-fields-video-field/02-fields-video-data-entry.png)

Поля отображаются в статье только в том случае, если для них указаны данные в форме ввода данных статьи.

## Отображение данных

На следующем снимке экрана сайта показано поле, отображаемое в статье. Опция *Автоматическое отображение*
отвечает за положение поля, а ваш шаблон — за оформление поля.
