## Назначение

Поле «Аудио» позволяет выбрать аудиофайл из папки мультимедиа.

## Создание поля

Общие параметры полей описаны в отдельной статье.

* **Заголовок** Заголовок отображается и используется в списке полей.
* **Метка** Это то, что отображается в выходных данных. Если оставить поле пустым, значение берётся из содержимого поля «Заголовок», но его можно изменить.

![создание поля аудио](../../../en/images/fields/adding-custom-fields-audio-field/01-fields-audio-edit.png)

**Примечание:** В этом примере включение типа поля в заголовок предназначено только для демонстрации. В собственных заголовках полей не указывайте тип поля.

## Ввод данных

Использовать поле «Аудио» просто. Выберите нужный аудиофайл с помощью медиаменеджера.

На следующем снимке экрана показан выбранный аудиофайл:

![ввод данных поля аудио](../../../en/images/fields/adding-custom-fields-audio-field/02-fields-audio-data-entry.png)

Поля отображаются в статье только в том случае, если в форме ввода данных статьи для них указаны значения.

## Отображение данных

На следующем снимке экрана сайта показано поле, отображаемое в статье. За положение поля отвечает параметр *Автоматическое отображение*, а за его оформление — шаблон.
